# 🥋 DojoTech - Sistema de Gerenciamento e Análise de Desempenho para Academia de Artes Marciais

## Visão Geral

O **DojoTech** é uma aplicação Full Stack desenvolvida para gerenciar e analisar o desempenho de alunos em uma academia de artes marciais. O projeto cumpre os requisitos do Desafio Individual, integrando Backend, Banco de Dados, Frontend com visualização de dados e conceitos de Algoritmos/Matemática.

## 🚀 Tecnologias e Ferramentas

| Categoria | Tecnologia | Função Principal |
| :--- | :--- | :--- |
| **Frontend** | HTML, CSS, JavaScript (JS) | Interface do Usuário e Interatividade. |
| **Visualização** | **Chart.js** | Geração do Dashboard com gráficos de desempenho. |
| **Backend (API)** | **Node.js** (API para Login/Cadastro pronta) | Manipulação e roteamento de dados. |
| **Banco de Dados** | **MySQL** | Persistência de dados de Alunos, Treinos e Graduações. |
| **Infraestrutura** | **VM Linux** | Hospedagem do Banco de Dados. |
| **Governança** | **Git/GitHub, Trello** | Controle de versão e planejamento. |

## 📊 Principais Funcionalidades

* **Dashboard de Desempenho:** Visualização de KPIs e gráficos (Chart.js) para análise coletiva e individual.
* **Controle de Alunos e Graduações:** Cadastro, gerenciamento de faixas e datas de promoção.
* **Cálculos Matemáticos:** Aplicação de funções JS/Algoritmos para gerar métricas de desempenho (ex: Frequência Média e Nota de Habilidade).

## 🛠️ Como Iniciar

1.  Clone o repositório: `git clone https://github.com/Tevezx/dojotech.git`
2.  Configure o Banco de Dados (**DojoTech**) na VM Linux e execute o script de criação de tabelas.
3.  Inicie a API Node.js no diretório `backend`: `npm install` e `npm start`
4.  Abra o arquivo `index.html` ou use um servidor local para visualizar o frontend.
